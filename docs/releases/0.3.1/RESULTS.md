## 真实模型尝试与费用边界

用户批准最多 16 次请求、每次最多 1,024 输出 token，只用订阅额度；随后允许先试免费 DeepSeek，并提供本机密钥图片，说明账户余额为零。

1. OpenCode 1.18.15 官方客户端、隔离配置、合成软件测试、一请求传输门禁：DeepSeek V4.1 Flash Free 返回 HTTP 429 `FreeUsageLimitError`。没有模型输出；没有重试或收费回退。
2. 真实 DSH rc.2 SDK 创建人物、显式绑定、干净续接、插件实际组装请求，由实验用受限传输适配器访问 Go 专属端点：HTTP 401 `Invalid credential`。请求 JSON 为 3,628 UTF-8 字节，输出上限 1,024；没有模型输出或 usage。密钥来自图片 OCR，未确认是否存在字符识别偏差，不能据此断言账户失效。

共 **2 次外部请求，0 个可评分输出**。没有完成计划的真实模型对照，不得用固定 scorer 代替，也不能从缺失 usage 推导已扣费金额为零。未修改生产宿主供应器、充值或启用额外用量；密钥只保存在本机加密配置。公开 evidence 只有脱敏元数据，不含凭据、正式资料或私聊历史。

官方边界核对：[Go 订阅、端点与额外用量](https://opencode.ai/v2/docs/console/go/)、[免费模型与使用范围](https://opencode.ai/v2/docs/console/models/)。这次是 SDK + 实验传输的尝试，不冒充完整 DSH 桌面供应器验收。

## 数据兼容与仍然存在的限制

- branch/global v1、host journal v2 保留；显式人物核心的 `rp.person-injection/v1` 能力标记会让旧 0.3 读取器拒绝升级后的工作区。新 document/experience 回执字段也有严格拒绝规则。升级前停止旧写入者、备份完整 profile / 工作区；回退恢复完整备份。
- 读取发布代数只共享同一进程、同一解析路径的工作区；发生发布交错可返回 `stale_input`，不宣称支持多进程并发写同一库。
- AI 经历默认关闭，候选与采纳分开；写后未知保持 `persistence_uncertain`，准入预扣不退款，不自动重发 ambiguous 输入。modeEpoch 边界保留。
- 相似复核是有限的词法建议；只覆盖有归属且可认证的有效经历，存在改写漏召回和话题相近误提示。没有向量索引或生产依赖传播算法替换。
- 历史、确认归档、普通对话和工具结果仍增长；检索、认证与恢复不是恒定成本。本地请求大小不是实际账单。
- AstrBot 是管理桥。完整模型注入、QQ / NapCat / Snow Luma、完整 rc.3 桌面安装、生产资料升级、真实断电、多日负载、其他 OS、完整移动端/键盘/读屏器矩阵和真实模型长期效果仍未验证。
