# Memory-Continuity 0.3 · 让记忆看得见，也管得住

人物会随着相处变得丰富，但不该变成一份越来越难读、也越来越贵的上下文。

这一版把两件事放在一起：重新整理工作台，让人物、经历和变化更好阅读；沿着真实调用链检查记忆的发送与恢复，让重复输入和重试有明确边界。

## 一个可以慢慢使用的工作台

暖白、墨青与宋体标题回来了，也保留了深色模式。人物卡片、档案分组、经历时间线、双向关系、目标与承诺各有自己的阅读方式。侧栏查看的是谁，顶部正在和谁聊天，会分别显示，浏览档案不会偷偷换掉聊天人物。

成长审阅能对照当前与建议状态、查看支持经历，再选择采纳、拒绝或修改后重新提案。注入预览会说明哪些记忆被选入、哪些没有，以及原因和最终文字。页面中的计量会区分字节与记忆预算，不把它们写成实际账单。

设置里可以切换人物视图、授权回忆检索、成长建议三个已有模块，也能调整用途与行为规则。开关先预览、确认后保存；已有聊天历史时先干净续接。影响弹窗可以关闭，页面内的明确确认仍然保留。尚未接入的创作大纲和项目看板不会冒充可用功能。

## 整理可以轻一点，确认仍在你手里

- **按需摘录候选**：从已接受的对话原文生成带来源的本地摘录，同一状态下重复操作复用候选。需要你采纳后才成为正式摘要，不额外调用模型。
- **轻量复核**：列出同角色精确重复、已有冲突、久未复核的信息和未完成约定；提出建议，不擅自改写历史。
- **会话交接预览**：一起查看关键用户原话、当前状态、有方向的关系、有效经历与待办，再明确开启新会话。
- **长资料修订**：重新解析后帮助匹配旧章节，提示可能沿用的分类和条件。先填回草稿、再核对确认，不因标题相似自动扩大注入范围。

这些是本地整理工具，不是已完成真实模型验证的语义总结或自主“做梦”。

## 长期对话的开销更有边界

不变的工具步骤会复用已经认证的当前记忆上下文，旧完整记忆包不会逐轮叠加到发送视图。每次明确输入默认最多进入适配器 16 次，每步最多重试 2 次；请求前先持久保存计数，失败不会绕过限制继续调用。

原话、必要记忆和工具历史仍保留。普通历史与退役占位也仍会增长，长会话需要显式 `continue-clean`。**适配器次数、内部请求字节和真实供应商账单是三回事，本版没有宣称节省某个百分比。**

## 升级之前

请关闭旧实例，备份整个 profile 与工作区，并先在独立空间验证。branch/global store 仍是 v1，host journal 仍是 v2，但新增了严格校验的请求计数，旧读取器可能拒绝新版记录。回退时恢复完整备份，不要删除字段或能力标记来骗过旧读取器。

不能认证的旧工具历史仍会进入恢复流程；结果不明的输入不会自动重发。已有历史的会话修改用途、模块或注入配置，需要先干净续接。

仍未验证真实模型长期人格质量、实际费用、完整 DSH 桌面安装、QQ 收发、多日运行、移动设备与完整读屏器矩阵。没有调用付费 API，没有开启后台自动摘要、自动采纳或压缩。
