# Memory-Continuity 0.2.0 · 首个正式版

让会话可以结束，让你塑造的人物继续。

Memory-Continuity 是面向 DSH 的独立人物连续性与长期记忆插件。你可以定义人物的身份、背景、性格、价值观与边界，记录共同经历、定向关系和未完成的承诺，再明确审阅人物怎样发生变化。这个正式版确定的是当前功能与协议边界，并不声称模型拥有真实人生或已经证明长期人格质量。

## 本版包含

- **人物工作台**：接入真实宿主的人物列表、创建与单字段编辑、经历和时间线、定向关系、目标/承诺、成长提案与人工采纳。浅色、深色和跟随系统主题，无 CDN 依赖。
- **分层与条件注入**：自我核心、当前处境、关系背景、相关往事、未完成事项五类记忆；概览、关联、证据三级展开；依据当前有效记录、明确规则和预算选择。
- **真实原因预览**：显示服务端实际选择结果、未选原因、UTF-8 字节用量、记录与来源编号以及本轮供模型阅读的文本，同时提示旧宿主上下文仍携带的内容。
- **干净续接**：新根会话继承有效人生线、人物和配置，保留后端记忆，不复制旧宿主消息、不自动重发不确定输入。
- **可靠性边界**：保留来源认证、版本栅栏、retcon 递归失效、删除保护、批量撤回、容量限制、seal 恢复和明确迁移备份。
- **独立使用**：通用偏好与世界记忆、全局发布/撤销/采用、分段存储和备份继续可用；无需 Ultra Mode。用途框架提供 RP、陪伴、创作、项目助手和三个内置模块，模块默认关闭。

管理页写入采用“读取快照 → 服务端生成确认预览 → 明确确认”。浏览器只保存主题，令牌仅保留在内存；关闭入口会真实撤销凭证并清空页面。页面刷新后需重新从宿主打开，不能收藏带令牌的地址作为永久入口。

## 安装与升级

下载附件中的插件 TGZ，按 [安装说明](../../rp-memory-design.zh.md) 与 [管理和存储说明](../../person-studio-storage.zh.md) 安装。包名为 `@dsh-external/dsh-memory-continuity`；最低 Node 22，本次使用 22.23.3。兼容声明固定为 DSH `0.2.1-rc.2`、Cordis `4.0.5`、Schemastery `3.18.5`。

先备份完整 profile 和工作区，在独立 profile 中核对实际路径、可信 entityIds、预算及合作写入者，再启用。不要同时加载旧包与新包。安装不等于启用；完整命令见 [中文指令速查](../../COMMANDS.zh.md)。

```text
/memcont help
/memcont start
/memcont person manage
```

主命令为 `/memcont`，旧 `/rp` 是兼容别名，没有 `/mc`。历史 `rp-memory` 配置节点、`.dsh-rp` 数据目录和 `rp_memory_*` 工具名称继续保留。branch/global v1 不变；host journal v2 的认证与 M5 扩展按既有规则严格拒绝无法验证的旧历史。启用人物能力或 M5 时的显式备份/新版读取要求继续适用，不做未经验证的自动历史迁移。

## 验证与已知限制

实际命令、完整 suite、实际 TGZ 与 CU 证据见 [正式版 RESULTS](RESULTS.md)。所有测试均未调用付费 API；真实 SDK 验证使用离线终端适配器，不能当作真实模型语义评测。

- 已覆盖桌面浏览器的主要交互；窄屏、移动设备、完整键盘/读屏器矩阵尚未验收。
- 检索使用有界本地词法，不是语义向量。预算是 UTF-8 保守估算，不是准确 tokenizer 或账单。
- 页面查看人物不会切换聊天绑定人物；注入预览以当前聊天绑定为准。旧上下文中的内容不会因为本轮排除而自动擦除，需要删除与干净续接流程。
- 日常生产 profile 升级、真实断电、多日长跑、跨 OS/SDK 与并发上限未验证。历史偶发构建/归档问题及长链性能限制保留在报告中。
- 后台自动摘要、自动采纳、自动压缩均未开启。单会话压缩已从当前产品范围移除；本轮未新增 Ultra Mode 兼容验收。

## 未来可能做的功能

这些是后续方向，**没有在本版实现，也不是交付承诺**：

1. 技能与做事经验：从可核对经历整理可复用经验，经人工审阅后采用。
2. 更完整的用途界面：为陪伴、创作和长期项目提供适合各自任务的交互。
3. 更深的长期检索与维护：提升大历史查询、认证性能，研究归档、备份和空间管理。
4. 更丰富的人物编辑：字段增删、别名、关系展示、日期规则，以及明确授权的多人物协作。
5. 跨模型、跨设备与长期使用评测：衡量连续性质量，继续区分记录一致性和模型语义表现。

附件包含插件包、完整开发源码、验证证据与 SHA-256 校验。源码 ZIP 可独立构建；需要 Git 历史的旧 reader 回归应从仓库克隆执行。仅发布 GitHub Release，本版不向 npm registry 发布。
