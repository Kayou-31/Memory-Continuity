# Memory-Continuity 前端功能需求

Memory-Continuity 是一个帮助用户创建和长期培养 AI 人物的开源项目。用户可以定义人物的身份、性格、价值观和表达方式，让人物记住经历、维持关系、推进目标，并在更换会话后延续这些内容。

需要一个中文优先、清晰易用的人物与记忆工作台。功能如下。

## 1. 人物管理

- 查看人物列表、切换正在查看的人物、新建人物。
- 查看和编辑身份、背景、性格、价值观、边界、表达方式。
- 展示人物当前的感受和人生阶段，并显示适用范围或有效期。
- 为不同内容设置“保持稳定”“允许成长”“仅当前情境有效”。
- 清楚区分“正在查看的人物”和“当前聊天使用的人物”。
- 创建、编辑时先预览，确认后再保存。

## 2. 经历与人生时间线

- 查看人物已经确认的经历，支持展开详情和查看来源。
- 记录新经历，填写参与人物、事件内容与相关时间。
- 按时间展示人物的重要经历与变化。
- 能看清某次变化之前是什么、之后是什么、为什么改变。
- 区分已确认内容与尚未确认的候选内容。

## 3. 关系管理

- 查看人物与其他人的关系、当前状态和变化原因。
- 支持记录新的关系变化，并关联支持这次变化的经历。
- 清晰展示关系方向，例如“林澈信任小贝”不自动表示“小贝也信任林澈”。
- 展示关系中尚未解决的矛盾或问题。

## 4. 目标与承诺

- 查看人物正在进行、已暂停、已完成和已放弃的目标。
- 创建目标或对某人的承诺，填写目标内容、对象、进度和下一步。
- 人工更新进度和状态，并说明变化原因。
- 让未完成事项容易被找到，同时保留已结束事项的历史。

## 5. 成长审阅

- 查看待确认的成长建议。
- 并排展示当前状态、建议的新状态、变化理由和支持经历。
- 支持提出成长建议、逐项采纳、批量采纳和拒绝。
- 所有采纳和修改都先展示确认预览，不自动写入。
- 如果数据在审阅期间发生变化，应提示刷新并重新检查。

## 6. 记忆注入预览（本次重点）

- 用户输入一句话题或问题，预览人物在这次对话中会用到哪些记忆。
- 按五类展示：**自我核心、当前处境、关系背景、相关往事、未完成事项**。
- 展示每条记忆是否选入，以及原因，例如必须保留、与话题相关、条件未命中、手动排除、容量不足。
- 显示展开深度：概览、关联、证据。
- 可以查看记忆来源和版本信息，便于核对。
- 展示本轮供模型阅读的人物记忆文本。
- 单独展示旧会话仍携带的历史，以及已经失效、会阻止继续发送的内容。
- 明确提示：本轮未选入某条记忆，不代表它已经从旧会话中消失。
- 预览只是查看，不发送模型、不修改记忆。

## 7. 会话延续与通用记忆

- 查看人物跨会话保留的记忆、偏好和共同设定。
- 区分当前人生线的记忆与跨会话使用的通用内容。
- 对需要开启新会话继续的情况，提供清楚的提示，让用户知道哪些内容会延续。
- 不把换会话表现成重新创建人物或丢失全部经历。

## 8. 用途与规则

- 查看当前用途，例如角色扮演、陪伴、创作或项目助手。
- 查看已启用的能力模块和人物规则。
- 清晰区分系统固定约束与用户自定义的人物规则。
- 对需要更换会话后才能调整的设置，给出明确操作提示。

## 9. 通用交互与视觉

- 统一使用项目名 **Memory-Continuity**，中文为主要界面语言。
- 支持**浅色、深色、跟随系统**，记住用户选择的外观。
- 导航清晰，能快速进入人物、经历、关系、目标、成长审阅和注入预览。
- 正常处理空列表、加载中、成功、失败、内容过长和入口失效等状态。
- 长名字、长中文、长来源编号不能挤坏布局。
- 桌面和手机窄屏都能正常使用，支持键盘操作和清晰焦点。
- 危险或重要操作必须有明确确认；失败时给出下一步提示，不能继续展示过时的成功结果。
- 提供手动刷新与关闭管理入口。

## 本次范围

先完成上述工作台功能。现有参考页面和视觉图仅供参考；页面结构、布局和视觉由设计方自行组织。

这次不需要做聊天窗口、自动总结、自动成长采纳、自动压缩、后台任务、模型付费调用或第三方插件市场。
