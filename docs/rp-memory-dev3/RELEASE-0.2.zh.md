## 本版可以做什么？

- **定义人物。** 创建身份、背景、表达、价值观、边界和性格等字段，支持稳定、可成长和情境有效的设置。
- **积累有来源的记忆。** 记录经历、定向关系、目标与承诺，保留前驱和原因；纠正、删除和人生分支继续遵循已有一致性检查。
- **人工审阅成长。** 成长先进入候选队列，检查原因后单项或批量采纳，也可拒绝；未确认的候选不会成为事实。
- **使用人物工作室。** 在 RP 会话执行 `/rp person manage`，打开返回的本机地址，统一查看和修改档案、经历、关系、目标及成长。每次写入先预览、再确认；`/rp person manage-close` 关闭入口。
- **按用途配置能力。** 提供角色扮演、陪伴、创作、项目四种用途框架，以及人物查看、记忆检索、成长审阅三个模块。模块默认关闭，系统硬约束与用户规则共同生效。
- **手动扩展全局存储。** 指定作用范围、完成备份和校验后，才可启用分段布局。默认普通发布／控制操作上限保持 3／4 MiB；分段模式为 8／12 MiB，保留全部事务及幂等历史。

后台自动摘要、原生上下文压缩、严格角色视角、自动采纳和自主行动继续关闭；没有接入付费模型 API。人物工作室只由人工命令启动，不运行后台轮询。
