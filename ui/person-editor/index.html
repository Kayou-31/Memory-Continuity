ULTRA-RP-MEMORY / PERSON CORE

给一个人，写下他的起点。

身份、来处、表达和在乎的事。先定义他是谁，再让共同经历留下可追溯的变化。

离线编辑 · 不连接模型 · 不写入记忆库 · 只有在宿主确认后才生效

01 / 人物定义

这里的 ID 用来关联同一个人物。输入一个新 ID 不会自动获得宿主授权。

02 / 关系与愿望

关系从当前人物指向对方。初始目标从「进行中 · 0%」开始。

03 / 检查与导出

草稿可以反复修改。导入宿主后先预览，再明确确认；创建成功后，在空会话中选择这个人物开始互动。

尚未创建人物。填写完成后生成草稿。

在 DSH 中完成创建
  1. 进入空的根会话，执行 /rp start。
  2. 粘贴生成的 /rp person preview … 命令，检查人物及升级提示。
  3. 执行 /rp person confirm 预览ID。
  4. 执行 /rp person use 人物ID，再用 /rp input … 开始。

首次创建前，插件会备份对应工作区。启用后整个工作区需要新版读取；回退必须恢复完整备份。已有宿主消息的会话要先 continue-clean 才能切换人物。

留出改变的空间

「保持稳定」用于身份与明确边界；「可经确认成长」用于允许由经历支持的变化。任何成长仍需人工确认。

未填写的项目保持未设定。人物草稿、导出文件和升级备份由你保管，插件删除记忆时不会自动删除这些外部副本。

本编辑器只处理人物初始定义，不导入外部工具历史、身份授权或真实行动回执。可独立使用 Memory-Continuity，也可与兼容 Ultra Mode 叠加。
